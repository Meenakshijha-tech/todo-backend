 # To-Do Backend

A beginner-friendly To-Do application built while learning Node.js and Express.js.

## Features

- Home page
- About and Contact routes
- HTML form to enter a task
- Add tasks to an in-memory array
- View all tasks
- Delete tasks by index

## Technologies Used

- Node.js
- Express.js
- HTML
- Git and GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Meenakshijha-tech/todo-backend.git
cd todo-backend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the server

```bash
node app.js
```

Open http://localhost:3000 in your browser.

## Note

Tasks are currently stored in memory, so they are lost when the server restarts. Database storage will be added as the project develops.

## Learning Goals

This project is helping me practice Express routes, request handling, query parameters, and basic task management.
